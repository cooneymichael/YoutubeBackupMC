# Youtube Backup MC

## Current State of the Project

Currently, this project consists only of a small script to access a youtube account, download links to
all videos in a playlist, as well as to all subscriptions, and then to save them in a pickled format.

In the future, a feature will be added to store the pickled data in a sqlite database for easier access
and management.

All files in this project are generated by Claude Sonnet 5.5.  Minor modifications have been made by myself.
